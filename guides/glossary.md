# Glossary

Last updated: 2026-11-17

Plain-language definitions of terms used in the guides.

- **Idempotent:** doing the same request twice has the same effect as doing it once.
- **Signaling:** the setup messages that let two WebRTC peers find each other.
- **TURN:** a relay server used when a direct WebRTC connection fails.
- **Protobuf:** the compact binary data format gRPC uses.
- **Pub/sub:** senders publish to a broker and receivers subscribe; they never talk directly.
- **At the edge:** the layer that outside clients talk to.
- **Time-series database:** stores measurements over time, such as sensor readings.
- **Row Level Security:** a database rule limiting which rows each user can read or write.
- **JSONB:** a PostgreSQL column type that stores flexible JSON.
- **Exclusion constraint:** a PostgreSQL rule that rejects overlapping rows.
